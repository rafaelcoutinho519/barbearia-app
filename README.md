# 💈 Brooklyn Barbearia — Sistema de Agendamento

> Sistema web completo para gestão de barbearias, desenvolvido para otimizar o fluxo de atendimento de clientes, controle de horários por profissional e painel administrativo automatizado.

---

## 🚀 Sobre o Projeto

Este projeto foi desenvolvido para atender a uma demanda real do mercado local, unindo usabilidade, design moderno (Dark Mode) e automação de processos. A aplicação conta com agendamento dinâmico baseado na agenda individual de cada barbeiro, bloqueio de horários passados/indisponíveis e validação de regras de funcionamento.

---

## 🛠️ Tecnologias e Stack Utilizada

O projeto foi construído com uma arquitetura leve e performática:

* **Frontend:** HTML5, CSS3 e JavaScript puro (Vanilla JS), proporcionando carregamento rápido e interatividade fluida.
* **Backend:** Node.js com Express para gerenciamento de rotas e lógica de negócios.
* **Banco de Dados:** SQLite, garantindo persistência local rápida e estruturada.
* **Controle de Versão:** Git e GitHub para versionamento e gestão do código-fonte.
* **Hospedagem & Deploy:** Railway (Ambiente de produção online).

---

## 📋 Funcionalidades Principais

* **Agendamento Inteligente:** Seleção de serviços, escolha de profissionais específicos (Karlos, Dorgivan e David) com regras de horários personalizadas para cada dia da semana.
* **Validação de Conflitos:** O sistema impede automaticamente o agendamento em horários já ocupados ou em períodos de intervalo/almoço.
* **Painel Administrativo:** Área restrita para os barbeiros gerenciarem os agendamentos do dia e acompanharem o fluxo de atendimento.
* **Responsividade:** Layout adaptado para dispositivos móveis e desktops.

---

## 🔍 Foco em Qualidade e Boas Práticas (QA)

Durante o desenvolvimento deste software, foram aplicados conceitos fundamentais de qualidade de código e testes:
* Validação de cenários de borda (limites de horários, dias fechados como domingos).
* Testes manuais funcionais e estruturados para reporte e correção de bugs na interface.
* Organização limpa do código e padronização de commits.
